# 项目功能实现与修改证明

## 1. 文档目的

本文档用于说明本项目当前版本中，主要功能是在哪些文件中完成的、做了哪些关键修改、如何验证结果，方便老师检查、课程答辩说明与后续维护。

本文基于当前实际项目结构编写，覆盖两个正式目录：

- `JPet_Store`：统一前端工程（Vue 3 + TypeScript + Vite）
- `pet-shop-backend`：后端工程（Spring Boot + Spring Security + JWT + Maven）

## 2. 当前项目结构

### 2.1 前端结构

当前前端不是单一的“商家页面集合”，而是一个统一工程，内部同时承载买家端、商家端、管理员端：

- `JPet_Store/src/views`：商家端与管理员端页面
- `JPet_Store/src/buyer/views`：买家端页面
- `JPet_Store/src/components`：商家端/公共布局组件
- `JPet_Store/src/buyer/components`：买家端组件
- `JPet_Store/src/api`：商家端、管理员端、统一 HTTP 与认证接口
- `JPet_Store/src/buyer/api`：买家端 API 聚合
- `JPet_Store/src/stores`：统一认证、商家端状态
- `JPet_Store/src/buyer/stores`：买家端状态
- `JPet_Store/src/router`：统一路由与角色守卫
- `JPet_Store/src/utils`：认证会话、图片路径、订单聊天等工具

功能说明：

- 买家、商家、管理员统一从同一个登录页进入
- 登录后根据角色自动跳转到买家首页、商家后台或管理员控制台
- 前端请求自动携带 JWT，并支持 token 刷新

前端实现文件：

- `JPet_Store/src/views/LoginView.vue`
- `JPet_Store/src/api/auth.ts`
- `JPet_Store/src/api/http.ts`
- `JPet_Store/src/utils/authSession.ts`
- `JPet_Store/src/stores/auth.ts`
- `JPet_Store/src/router/index.ts`

证明点：

- 登录页已经做成统一入口，并通过 tab 区分“买家”与“商家 / 管理员”

## 8. 微服务化改造（2026-11-04 新增）

在保留原有三端功能与前端零改动的前提下，后端已从单体拆分为 Spring Cloud Alibaba 微服务体系。

### 8.1 服务拆分

| 服务 | 目录 | 端口 | 数据库 | 职责 |
|---|---|---|---|---|
| gateway | `gateway/` | 8080 | — | Spring Cloud Gateway 统一入口 |
| user-service | `user-service/` | 8081 | `user_db` | 注册/登录/刷新、用户资料、管理员-用户 |
| product-service | `pet-shop-backend/` | 8082 | `commerce_db` | 商品/商家/认证/标签、SPA、uploads |
| order-service | `order-service/` | 8083 | `commerce_db` | 下单、订单、评价、商家订单 |

- 四个服务均注册 Nacos（`127.0.0.1:8848`），按服务名访问
- 服务间使用 OpenFeign，无硬编码 IP
- 外部请求统一经 gateway；`/internal/**` 不路由且需要 `X-Internal-Token`
- Spring Cloud Gateway 5.x 的路由前缀为 `spring.cloud.gateway.server.webflux.routes`

### 8.2 关键实现文件

- 共享内核：`pet-shop-common/`
- 内部用户接口：`user-service/.../controller/InternalUserController.java`
- 内部商品/库存接口：`pet-shop-backend/.../controller/InternalProductController.java`
- 内部订单接口：`order-service/.../controller/InternalOrderController.java`
- 下单编排：`order-service/.../service/OrderCheckoutOrchestrator.java`
- 补偿任务：`order-service/.../service/CheckoutCompensationJob.java`
- 网关路由：`gateway/src/main/resources/application.yml`
- 数据库初始化：`db/init/01_user_db.sql`、`db/init/02_commerce_db.sql`
- 容器编排：`deploy/docker-compose.yml`

### 8.3 新增真实 DELETE 接口
