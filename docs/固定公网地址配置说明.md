# 固定公网地址配置说明

当前项目已经支持两类访问方式：

- 局域网访问：`http://当前电脑IP:8080/spa/`
- 临时公网访问：通过 `localhost.run` 或 `Cloudflare Quick Tunnel` 临时生成

如果你要的是“长期固定、可反复使用、不随每次启动而变化的网址”，目前最稳的方案是 Cloudflare Tunnel 的命名隧道。

## 先说结论

在你**没有自有域名**的前提下，无法真正做成长期固定的网址。

原因不是项目代码，而是公网固定域名本身需要满足下面两个条件：

1. 你必须拥有一个自己控制的域名。
2. 该域名必须托管到 Cloudflare，才能把固定子域名绑定到你的本机隧道。

像 `trycloudflare.com`、`localhost.run` 这类免费地址，都只能给你临时或非承诺长期稳定的链接，不适合当作长期固定网址。

## 你现在已经准备好的内容

仓库里已经补好了以下文件：

- `cloudflared/config.example.yml`
- `scripts/start_cloudflare_quick_tunnel.sh`
- `scripts/start_fixed_cloudflare_tunnel.sh`

用途分别是：

- `config.example.yml`：固定隧道的配置模板
- `start_cloudflare_quick_tunnel.sh`：快速生成临时公网链接
- `start_fixed_cloudflare_tunnel.sh`：在你后续拥有域名并完成配置后，启动固定公网隧道

## 真正做成固定公网网址的步骤

### 1. 准备一个域名

你需要先购买一个域名，例如：

- `yourpetshop.com`
- `yourpetshop.xyz`
- `yourpetshop.top`

随后把域名的 DNS 托管切换到 Cloudflare。

### 2. 登录 Cloudflare Tunnel

安装完成 `cloudflared` 后，在终端执行：

```bash
cloudflared tunnel login
```

这一步会打开浏览器，让你登录 Cloudflare，并选择你托管的域名。

### 3. 创建命名隧道

```bash
cloudflared tunnel create jpet-store-web
```

执行后会得到一个固定的 Tunnel UUID，并在 `~/.cloudflared/` 目录下生成凭证文件。

### 4. 生成正式配置文件

复制模板：

```bash
cp cloudflared/config.example.yml cloudflared/config.yml
```

然后把下面两项改成你自己的值：

- `tunnel`: 改成 Cloudflare 返回的 Tunnel UUID
- `credentials-file`: 改成本机生成的 JSON 凭证文件路径
- `hostname`: 改成你自己的固定域名，比如 `shop.yourpetshop.com`

### 5. 绑定固定子域名

```bash
cloudflared tunnel route dns jpet-store-web shop.yourpetshop.com
```

执行后，`shop.yourpetshop.com` 就会固定指向你的隧道。

### 6. 启动固定公网隧道

```bash
./scripts/start_fixed_cloudflare_tunnel.sh
```

你的同学以后就可以一直用这个固定链接访问：

```text
https://shop.yourpetshop.com/spa/
```

## 可选：把隧道做成开机自启

如果你不想每次手动启动，可以执行：

```bash
cloudflared service install
```

或者使用 Homebrew 服务：

```bash
brew services start cloudflared
```

注意：只有在你的 `config.yml` 已经正确配置后，再做这一步才有意义。

## 当前可直接使用的替代方案

在你还没有域名之前，建议这样用：

### 局域网

同一 Wi-Fi/热点下访问：

```text
http://当前电脑IP:8080/spa/
```

### 临时公网

执行：

```bash
./scripts/start_cloudflare_quick_tunnel.sh
```

它会生成一个 Cloudflare 临时公网地址。这个地址不是固定的，但适合现在给同学临时演示。

## 结合你当前项目的注意事项

1. 你的前端入口路径不是根路径，而是 `/spa/`，所以分享地址时必须带上 `/spa/`。
2. 后端服务必须保持运行在 `8080` 端口。
3. 你的电脑一旦关机、休眠、断网，公网访问就会中断。
4. 如果你要真正长期稳定给同学访问，最合理的做法仍然是：买一个便宜域名，然后走 Cloudflare Tunnel 命名隧道。
